OllApeX

The model runs on all Apex Compute FPGA cards at the same time.
Ask something, or attach a file or an image; inference details appear on the right.
At temperature 0 the token is chosen on the cards. Above 0, each card reports its four best candidates and sampling happens among them, so top_k is at most 4.
